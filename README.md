# حسابیار آریا

نسخه اول نرم‌افزار حسابداری اختصاصی برای معاملات خودرو، اجاره به شرط تملیک، سرمایه‌گذاران، اقساط، چک‌ها و گزارش‌های مالی.

## اجرای محلی

```bash
npm install
npm run dev
```

سپس رابط کاربری روی `http://localhost:5173` و API روی `http://localhost:3001` در دسترس است.

## مدل داده

- `transactions`: ورود و خروج نقد، دسته‌بندی، طرف حساب و مرجع
- `checks`: چک‌های دریافتی/پرداختی، سررسید، وضعیت و مالک
- `installments`: برنامه اقساط، مبلغ وصول‌شده و وضعیت
- `contacts`: مشتری، سرمایه‌گذار و شرکت/صندوق
- `vehicles`: خودرو، پلاک، ارزش ثبت‌شده و وضعیت قرارداد
- `investors`: اصل سرمایه، نرخ توافقی و وضعیت

واحد ذخیره‌سازی مبالغ در این نسخه **ریال** است. داده‌های اولیه نمونه‌اند و برای ورود اطلاعات واقعی باید حذف یا جایگزین شوند.

## استقرار Railway

فرمان build و start در `railway.json` تنظیم شده است. برای حفظ داده‌های SQLite در استقرار دائمی، یک Volume به مسیر `/app/data` متصل شود و متغیر `DATA_DIR=/app/data` قرار بگیرد. برای مقیاس چندکاربره، مرحله بعدی انتقال دیتابیس به PostgreSQL است.
